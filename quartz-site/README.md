# Dolomiti Friulane — Wiki di viaggio (Forni di Sopra)

Wiki escursionistica per la vacanza 2026 a Forni di Sopra, generata come sito statico con [Quartz](https://quartz.jzhao.xyz/).

- Contenuto sorgente: cartella `content/` (copia di `../content-forni-di-sopra/`)
- Sito pubblicato via GitHub Pages (workflow in `.github/workflows/deploy.yaml`)
- Per aggiornare il sito dopo aver modificato le gite: ricopia i file aggiornati in `content/` e fai push su `main`

## Sviluppo locale

```bash
npm install
npx quartz build --serve
```
